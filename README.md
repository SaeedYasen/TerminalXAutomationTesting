# TerminalXAutomationTesting

Automation testing project for the **Terminal X** website.  
The project includes test logic, utility functions, and documented test plans.

## 📂 Project Structure

- **infra/**  
  Infrastructure and environment setup.
- **logic/**  
  Core logic for test execution and scenarios.
- **tests/**  
  Contains all automated tests with full coverage for sales filters.  
  - Includes **Parameterised** tests for the main page.  
  - Supports **annotations** such as *slow*.
- **utils/**  
  All helper functions are consolidated in a single file.
- **Terminal X Test cases.xlsx**  
  Excel file with test cases and test plan.
- **Test Plan for Terminal X Website.docx**  
  Comprehensive test plan document.

## ⚙️ Features

- Full coverage of sales filter tests.  
- Support for **Parameterized** tests for flexible scenarios.  
- Global wait time configuration with special handling for slow tests.
